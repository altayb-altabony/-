# مشروع HCI: التحكم بالحاسوب عن طريق إيماءات اليد

برنامج يفتح الكاميرا ويتعرف على حركة اليد مباشرة، ويعطي نتيجة مختلفة لكل إيماءة، دون استخدام الفأرة أو لوحة المفاتيح.

## طريقة التشغيل في VS Code

1. من `File > Open Folder` افتح مجلد المشروع `midia`.
2. افتح الملف `main.py`.
3. اضغط زر التشغيل ▶ أعلى يمين النافذة، أو شغّل هذا الأمر في الطرفية:

```bash
.venv\Scripts\python.exe main.py
```

للخروج اضغط `Q` أو `Esc`.

### التشغيل على جهاز آخر

لا تنقل المجلد `.venv` إلى الجهاز الجديد، بل أنشئه هناك. يحتاج ذلك إلى Python 3.13 واتصال بالإنترنت:

```bash
python -m venv .venv
```

```bash
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

```bash
.venv\Scripts\python.exe main.py
```

إذا كان في الجهاز أكثر من كاميرا أو لم تفتح الكاميرا، جرّب:

```bash
.venv\Scripts\python.exe main.py --camera 1
```

## الإيماءات ونتائجها

| الإيماءة | الشكل | النتيجة |
|---|---|---|
| كف مفتوح | ✋ | تشغيل / إيقاف |
| قبضة | ✊ | كتم الصوت أو إلغاؤه |
| إبهام لأعلى | 👍 | رفع الصوت (يتكرر مع استمرار الإيماءة) |
| إبهام لأسفل | 👎 | خفض الصوت (يتكرر مع استمرار الإيماءة) |
| السبابة | ☝️ | الشريحة التالية |
| السبابة والخنصر | 🤘 | الشريحة السابقة |
| علامة النصر | ✌️ | التقاط صورة وحفظها في `captures` |
| علامة OK | 👌 | إعادة ضبط الحالة |

ثبّت الإيماءة نصف ثانية تقريباً حتى يمتلئ الشريط ويُنفَّذ الأمر.

## الحماية: البطاقة ثم الوجه ثم الإيماءة

عند توصيل ESP32 مع قارئ البطاقات RC522، يبدأ البرنامج **مقفلاً** ولا ينفّذ أوامر الإيماءات حتى يتحقق من المستخدم بثلاث خطوات:

1. **البطاقة:** مرّر بطاقتك على القارئ.
2. **الوجه:** انظر إلى الكاميرا، فيقارن البرنامج وجهك ببصمة وجه صاحب البطاقة. يظهر إطار أخضر عند التطابق وأحمر عند عدمه.
3. **الإيماءة:** يطلب البرنامج إيماءة عشوائية، فنفّذها ووجهك ما زال أمام الكاميرا. هذه الخطوة تمنع الخداع بصورة مطبوعة.

بعدها يُفتح النظام ويضيء الـLED الأزرق باستمرار، ولقفله مرّر البطاقة مرة أخرى. وإذا فشلت أي خطوة يضيء الـLED الأحمر.

بدون ESP32 يعمل البرنامج كما كان، مفتوحاً وبدون حماية.

### تجهيز ESP32

1. وصّل القطع كما في الجدول، وانتبه أن القارئ يعمل على **3.3V وليس 5V**:

   | قارئ RC522 | ESP32 |
   |---|---|
   | SDA | GPIO 5 |
   | SCK | GPIO 18 |
   | MOSI | GPIO 23 |
   | MISO | GPIO 19 |
   | RST | GPIO 27 |
   | GND | GND |
   | 3.3V | 3.3V |
   | LED أزرق (مع مقاومة 220 أوم) | GPIO 32 |
   | LED أحمر (مع مقاومة 220 أوم) | GPIO 33 |

2. في Arduino IDE ثبّت مكتبة **MFRC522** من Library Manager، واختر لوحة ESP32.
3. افتح الملف `arduino/gesture_auth/gesture_auth.ino` وارفعه إلى اللوحة.
4. أغلق Serial Monitor، ثم شغّل البرنامج. سيكتشف منفذ اللوحة تلقائياً، وإذا لم يجده فحدده بنفسك:

```bash
.venv\Scripts\python.exe main.py --port COM5
```

رقم المنفذ يظهر في Arduino IDE من `Tools > Port`.

### تسجيل مستخدم

1. اضغط `R`.
2. مرّر البطاقة التي تريد تسجيلها.
3. انظر إلى الكاميرا ثانيتين تقريباً حتى يحفظ البرنامج 5 صور لوجهك.

يُحفظ المستخدمون في `faces/users.json` بأسماء مثل "مستخدم 1"، ويمكنك تغيير الاسم من هذا الملف. وإذا سجّلت البطاقة نفسها مرة أخرى، تُستبدل بصمات الوجه ويبقى الاسم.

**ملاحظات:**
- الملف `faces/users.json` يحتوي بصمات وجوه حقيقية، فاستأذن من تسجّل وجهه، ولا تنشر الملف.
- التسجيل متاح لأي شخص يضغط `R` على لوحة المفاتيح، وهذا مناسب للعرض فقط وليس لنظام حماية حقيقي.

## وضعا التشغيل

- **الوضع العادي (الافتراضي):** تظهر النتائج داخل نافذة البرنامج فقط، وهو الأنسب للعرض أمام المدرّس.
- **وضع التحكم بالحاسوب (اضغط `M`):** يضغط البرنامج مفاتيح حقيقية، فيتغير صوت الجهاز ويعمل التشغيل والإيقاف.
  أوامر الشرائح ترسل السهمين يميناً ويساراً إلى النافذة النشطة، لذلك اضغط `M` ثم انقر على نافذة PowerPoint.
  أما الصوت المعروض في البرنامج فهو عدّاد داخلي، وقد يختلف عن صوت الجهاز الفعلي.

## كيف يعمل البرنامج

```
الكاميرا (OpenCV) ← كشف 21 نقطة في اليد (MediaPipe) ← تصنيف الإيماءة (gestures.py)
   ← تثبيت الإيماءة (GestureStabilizer) ← تنفيذ الأمر (main.py) ← عرض النتيجة للمستخدم
```

**تحديد الأصابع المفرودة:** يكون الإصبع مفروداً إذا كان طرفه أبعد عن الرسغ من مفصله الأوسط بنسبة واضحة. وتحدد مجموعة الأصابع المفرودة نوع الإيماءة. هذه الطريقة تعمل حتى لو كانت اليد مائلة، لأنها تعتمد على المسافات لا على مكان الإصبع في الصورة.

## مفاهيم HCI المطبقة (مفيدة عند المناقشة)

| المفهوم | كيف طُبّق في البرنامج |
|---|---|
| **الواجهة الطبيعية (NUI)** | التحكم بحركة اليد بدل الأجهزة التقليدية |
| **التغذية الراجعة (Feedback)** | رسم هيكل اليد، وإظهار الإيماءة الحالية، وشريط التقدم، ورسالة النتيجة |
| **مشكلة لمسة ميداس (Midas Touch)** | ألا تتحول كل حركة عفوية إلى أمر؛ وعالجناها بزمن الثبات |
| **زمن الثبات (Dwell Time)** | لا يُنفَّذ الأمر إلا بعد تثبيت الإيماءة 0.6 ثانية |
| **تقليل الأخطاء (Error Prevention)** | تصويت الأغلبية على آخر 7 إطارات لإزالة التذبذب، وعدم تكرار الأمر حتى تتغير الإيماءة |
| **سهولة التعلم والتذكر (Learnability)** | جدول الإيماءات ظاهر دائماً على الشاشة، فلا يحتاج المستخدم إلى حفظها |
| **تحكم المستخدم (User Control)** | التحكم الفعلي بالحاسوب متوقف إلى أن يفعّله المستخدم بالمفتاح `M` |
| **التفاعل متعدد الوسائط (Multimodal Interaction)** | الجمع بين البطاقة والوجه وحركة اليد في نظام واحد |
| **التحقق متعدد العوامل (Multi-factor Authentication)** | شيء يملكه المستخدم (البطاقة) مع شيء يخصه هو (الوجه) |
| **كشف الحيوية (Liveness Detection)** | إيماءة عشوائية تثبت وجود شخص حقيقي لا صورة مطبوعة |
| **التغذية الراجعة المادية (Physical Feedback)** | الـLED: يومض أثناء الانتظار، وثابت عند الفتح، وأحمر عند الرفض |

## ملفات المشروع

| الملف | وظيفته |
|---|---|
| `main.py` | الكاميرا، والواجهة، وتنفيذ الأوامر |
| `gestures.py` | تصنيف الإيماءات وتثبيتها |
| `auth.py` | مراحل فتح القفل: البطاقة ثم الوجه ثم الإيماءة |
| `face_auth.py` | اكتشاف الوجه والتعرف عليه، وحفظ المستخدمين |
| `esp32.py` | الاتصال بلوحة ESP32 عبر USB |
| `arduino/gesture_auth/gesture_auth.ino` | الكود الذي يُرفع إلى ESP32 |
| `models/` | نماذج اليد والوجه (تُحمَّل تلقائياً إذا لم تكن موجودة) |
| `requirements.txt` | المكتبات المطلوبة |

## لتغيير نتيجة إيماءة أو حساسيتها

- **نص النتيجة:** الجدول `GESTURES` في `main.py`.
- **ما تفعله الإيماءة:** الدالة `App.handle` في `main.py`.
- **زمن الثبات:** القيمة `hold_seconds` في `GestureStabilizer`.
- **أوقات الحماية وعدد صور التسجيل:** القيم في أعلى `auth.py`.
- **دقة مطابقة الوجه:** القيمة `MATCH_THRESHOLD` في `face_auth.py`. رفعها يجعل المطابقة أصعب، وخفضها يجعلها أسهل.

## نصائح لأفضل دقة

- إضاءة جيدة وخلفية غير مزدحمة.
- اجعل اليد على بعد 40 إلى 80 سم من الكاميرا.
- الإضاءة الضعيفة تُبطئ الكاميرا نفسها، فيقل عدد الإطارات في الثانية ويتأخر التعرف.
- سجّل وجهك في الإضاءة نفسها التي ستعرض فيها المشروع.
- ارفع يداً واحدة فقط، فالبرنامج يتابع يداً واحدة.
- وجّه باطن الكف نحو الكاميرا في الكف المفتوح وعلامة النصر وOK.
